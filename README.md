# XOFLIX TV Subscription Manager

> **Status: legacy public snapshot.**

WordPress plugin for XOFLIX TV subscription plans, users, payments, fulfilment, notifications and the customer dashboard. The snapshot identifies itself as version 3.9.27.

Current development is maintained in the private XOFLIX WordPress plugin monorepo. This repository should not be used as the source for new releases unless its tree has first been reconciled against that canonical monorepo.

## Requirements

- WordPress
- PHP compatible with the target WordPress installation
- Production SMTP/payment configuration supplied through WordPress settings

Never commit SMTP passwords, gateway credentials or customer data. This repository can be archived after confirming that no production deployment or external remote still pulls from it.
